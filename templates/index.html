About This Project

Project Overview

This interactive dashboard analyzes India's power generation data from 2013-2023 across different sources (thermal, hydro, solar, wind, etc.) and regions.

The system provides visual analytics tools to understand generation patterns, regional distributions, and predict future demand using multiple machine learning models with performance comparison.

Key Features
  • Interactive time-series visualizations with Plotly
  • Comparative analysis by source/region
  • Demand forecasting with 4 ML models
  • Side-by-side model performance metrics
  • Responsive design for all devices

Methodology

Data was sourced from the Central Electricity Authority of India's public records. The datasets include:

  • Daily generation by source (2013-2023)
  • State-wise demand and supply metrics

Data cleaning included handling missing values, standardizing units, and removing aggregate rows.

The project employs several analytical approaches:

  • Descriptive Analytics: Time series decomposition, regional comparisons
  • Predictive Modeling:
    • Linear Regression
    • Random Forest (200 estimators)
    • Support Vector Regression (RBF kernel)
    • Holt-Winters Exponential Smoothing
  • Model Evaluation: Accuracy, MSE and MAE metrics
  • Comparative Analysis: Renewable vs fossil fuel generation trends
